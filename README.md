## 📋 Overview

G-Bytes is a comprehensive brain training and wellness application that combines **cognitive games**, **productivity timers**, and **music features** into one engaging platform. Designed with Material 3 and developed in Flutter, G-Bytes helps users enhance focus, memory, and mental agility through scientifically-inspired exercises and gamification.

### 🎯 Key Highlights
- ✨ **5 Brain Training Games** - Memory, Logic, Math Sprint, Schulte Table, Stroop Effect
- ⏱️ **Advanced Timer Suite** - Classic timers and customizable HIIT interval training
- 🎵 **Music Player** - Curated focus music and custom track support
- 🏆 **21-Tier League System** - Progressive achievement tracking
- 🎨 **Customizable Themes** - 3 color schemes with dynamic theming
- 📊 **Performance Analytics** - High scores, streak tracking, and stats

## 🎮 Features

### 🧩 Brain Training Games

#### 1. **Memory Game** 🎯
Train your memory with pattern recognition
- Dynamic grid sizes: 3×3 to 5×5
- Progressive difficulty levels
- High score tracking
- Perfect for improving recall ability

#### 2. **Logic Game** 🧠
Enhance logical thinking with sequence completion
- Find the missing element challenges
- Multiple-choice answers
- Progressive difficulty
- Session scoring system

#### 3. **Math Sprint** ⚡
Rapid mental arithmetic in 60 seconds
- Multiple operators (addition, multiplication, division)
- Operator-specific scoring
- Streak tracking
- Challenge your speed and accuracy

#### 4. **Schulte Table** 👁️
Speed test for visual attention and processing
- Three difficulty levels (3×3, 4×4, 5×5 grids)
- Number spotting challenges
- Hard mode available
- Track your fastest times

#### 5. **Stroop Effect Test** 🌈
Test color-word cognitive interference
- Match displayed color names to ink colors
- Measures focus and reaction time
- Scientific cognitive test
- Excellent for attention training

### ⏱️ Timer Suite

#### Classic Timer
- **Countdown Mode**: Pre-set timers (5, 10, 25, 45 min, 1 hour) or custom
- **Stopwatch Mode**: Measure elapsed time
- **Audio Feedback**: Tick sounds and completion alerts
- **Visual Progress**: Real-time progress bar
- **Custom Animations**: Choose jellyfish, bubble burst, or stardust effects

#### Interval Timer (HIIT)
- **Customizable Workouts**: Set work/rest intervals and rounds
- **Work Duration**: 5-300 seconds
- **Rest Duration**: 0-300 seconds
- **Rounds**: 1-20 rounds
- **Audio Cues**: Alerts for phase transitions
- **Workout Planning**: Total time calculation before starting

### 🎵 Music Player

- 🎶 **10 Pre-loaded Tracks**: Curated ambient and focus music
- 📁 **Custom Audio**: Import your own tracks
- 🔀 **Shuffle & Repeat**: Full playback control
- 🎨 **Color-Coded Tracks**: Visual organization
- 🔊 **Background Playback**: Continue listening while using other apps
- 📱 **System Integration**: Notification controls

### 🏆 Progression System

- **21-Tier League System**: 7 leagues with 3 sub-levels each
- **Points Tracking**: Accumulate points across all games
- **Daily Progress**: Monitor daily point gains
- **Streak Rewards**: Consistency bonuses
- **High Score Records**: Per-game performance tracking
- **Real-time Stats**: Live progress updates

### ⚙️ Customization

- 🎨 **3 Theme Colors**: Orange, Cyan, Purple
- 🔊 **Sound Control**: Toggle sound effects
- 🎬 **Animation Selection**: Customize timer animations
- 🎯 **Difficulty Settings**: Schulte table hard mode
- 💾 **Persistent Preferences**: All settings auto-saved

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (v3.0 or higher) - [Install Flutter](https://flutter.dev/docs/get-started/install)
- Dart SDK (v3.0 or higher)
- Android SDK / iOS SDK
- Git

### Installation

1. **Clone the Repository**
```bash
git clone https://github.com/Asta-dev-378/G-Bytes.git
cd G-Bytes
```

2. **Install Dependencies**
```bash
flutter pub get
```

3. **Run the App**
```bash
flutter run
```

### Build for Release

**Android (APK)**
```bash
flutter build apk --release
```

**Android (Google Play App Bundle)**
```bash
flutter build appbundle --release
```

**iOS**
```bash
flutter build ios --release
```

## 📱 How to Use

### Getting Started
1. **Launch the App** - You'll see the splash screen
2. **Create Profile** - Enter your name on the login screen
3. **Access Dashboard** - View your stats in G-Zone

### Playing Games
1. Navigate to **G-Zone** tab
2. Tap **Training Hub**
3. Select a game (Memory, Logic, Math Sprint, Schulte, or Stroop)
4. Follow the in-game instructions
5. Complete and earn points!

### Setting Up Timers
1. Go to **G-Timer** tab
2. **For Classic Timer**:
   - Tap a preset (5, 10, 25, 45 min) or set custom time
   - Choose Countdown or Stopwatch mode
   - Hit Start!

3. **For HIIT Interval Timer**:
   - Tap "Interval Timer"
   - Set work duration, rest duration, and rounds
   - Review total time
   - Start your workout

### Playing Music
1. Navigate to **G-Tunes** tab
2. Browse available tracks (pre-loaded or custom)
3. Tap a track to play
4. Use controls: Shuffle, Repeat, Next, Previous
5. Adjust volume as needed
6. Music continues in background!

### Tracking Progress
1. View your **League Tier** on G-Zone
2. Check **Daily Points** accumulation
3. Monitor **Streak** for consistency rewards
4. Review **High Scores** per game
5. Access **Profile** for detailed stats

### Customization
1. Navigate to **Settings** (from Profile menu)
2. Adjust options:
   - 🎨 Select theme color
   - 🔊 Toggle sound effects
   - 🎬 Choose timer animation
   - 🎯 Enable Schulte hard mode
3. Changes auto-save!
